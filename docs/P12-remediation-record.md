# P12 整改与验收记录

整改日期：2026-08-05

## 整改内容

1. 新增 PostgreSQL 存储适配器，启动时幂等创建表结构，业务数据、用户、会话、告警处置记录和审计日志均可持久化。
2. Docker Compose 增加 PostgreSQL 服务、健康检查和持久卷，API 等待数据库就绪后启动；Web 容器通过 Nginx 将同源 `/api` 请求转发到 API 容器。
3. 密码采用 PBKDF2-SHA256 独立随机盐保存；首次管理员密码、数据库密码和 JWT 密钥全部从环境变量读取。
4. 访问令牌改为带签名和过期时间的 HS256 JWT，服务端同时校验签名、有效期、会话和用户状态。
5. 用户读取和用户写入权限分离，匿名请求返回 401，已登录但无权限的请求返回 403。
6. 登录页不再预填账号、密码或角色；新增用户密码不再使用默认值；密码重置改为管理员明确输入的新密码对话框。
7. 修复跨域预检缺少 Authorization 请求头，以及用户表格角色文字在 1280px 宽度下被截断的问题。
8. 清除仓库数据文件中的历史会话令牌和可复用演示凭据，旧数据启动时必须通过环境变量完成凭据轮换。
