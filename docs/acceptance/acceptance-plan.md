# 验收计划

## 1. 验收范围

- 文档完整性
- 工程规范完整性
- 核心业务流程可演示性
- 权限与审计可追溯性
- 部署说明可执行性

## 2. 验收标准

1. 采集节点管理、流量分析、异常告警、策略发布、报表导出流程均有明确设计。
2. 角色权限边界清晰，不存在职责冲突。
3. 接口规划、数据模型、页面清单可以支撑开发落地。
4. Git/GitHub 模板与 CI 规划齐全。
5. 本地至少可以完成文档结构校验。

## 3. 验收材料

- 产品与设计文档
- 测试计划
- 部署方案
- 本轮进展摘要
- 本地校验记录

## 4. 交付前检查

- [ ] `README.md` 存在且内容可读
- [ ] `docs` 七大子目录均有有效内容
- [ ] `.github` 模板和 workflow 齐全
- [ ] 本地执行 `scripts/validate-docs.ps1` 通过
- [ ] 下一阶段任务清单明确
