# 功能结构

## 1. 一级模块

| 一级模块 | 二级功能 |
| --- | --- |
| 首页驾驶舱 | 实时总流量、告警趋势、Top IP、Top 应用、待办处置 |
| 流量采集 | 采集节点、网络接口、采集任务、心跳监测、日志查看 |
| 流量分析 | 会话查询、协议分析、IP 排名、端口排名、应用排行、流量趋势 |
| 异常检测 | 检测规则、黑白名单命中、端口扫描识别、突增流量识别 |
| 管控策略 | 黑白名单、限流策略、阻断策略、发布审核、下发记录 |
| 告警中心 | 告警列表、告警详情、处置记录、超时提醒、复核归档 |
| 报表中心 | 日报、周报、月报、自定义导出、审计报表 |
| 系统管理 | 用户、角色、菜单、字典、参数、审计日志 |

## 2. 关键业务能力

### 2.1 流量采集

- 支持多采集节点注册
- 支持节点绑定多网卡
- 支持采集任务启停和策略配置
- 支持节点心跳、离线与异常状态管理

### 2.2 分析研判

- 支持按时间、IP、协议、端口、应用查询会话
- 支持 Top N 和趋势分析
- 支持异常流量快速钻取到原始会话

### 2.3 告警闭环

- 异常识别后生成告警
- 告警进入待研判队列
- 处置记录需保留处置人、动作、结果、附件
- 高危告警支持复核和升级

### 2.4 策略管控

- 策略新增、编辑、审批、发布
- 支持策略版本号和下发状态
- 记录策略命中次数，支持效果评估

## 3. 非功能要求

- 支持常见桌面分辨率使用
- 所有关键操作可审计
- 页面查询响应、报表导出和告警处置具备 SLA 约束
- 接口返回结构统一，便于前后端分离实现
