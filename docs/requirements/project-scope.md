# 项目范围说明

## 1. 建设目标

建设网络流量分析监测管控软件，形成“采集接入、流量识别、风险发现、告警处置、策略管控、报表审计”的业务闭环，支撑网络安全值守、运维分析和管理决策。

## 2. 业务边界

### 2.1 纳入范围

- 流量采集节点管理
- 网络接口与镜像流量接入配置
- 会话、协议、应用、IP、端口多维分析
- 异常流量检测与规则管理
- 告警工单式处置与复核
- 黑白名单、限流、封禁、放行等策略管理
- 大屏驾驶舱与统计报表
- 用户、角色、审计日志与系统参数管理

### 2.2 暂不纳入本期

- 深度包内容解密
- 自动联动第三方防火墙下发真实阻断指令
- 多租户结算与计费
- 移动端 App

## 3. 目标用户

| 角色 | 关注点 |
| --- | --- |
| 系统管理员 | 用户权限、系统参数、采集节点配置 |
| 网络管理员 | 流量接入、接口状态、网络运行质量 |
| 安全管理员 | 异常规则、告警处置、风险分析 |
| 审计员 | 报表导出、日志留痕、复核闭环 |
| 领导/监管人员 | 趋势看板、风险总览、处置时效 |

## 4. 交付物范围

- 产品需求与流程文档
- 页面结构与权限矩阵
- 数据模型与接口规划
- 测试计划、部署方案、验收标准
- Git/GitHub 规范、Issue/PR 模板、文档校验 CI

## 5. 里程碑建议

| 阶段 | 目标 |
| --- | --- |
| M0 | 文档和工程规范基线 |
| M1 | 认证、权限、菜单、系统管理 |

| M3 | 异常检测、告警处置 |
| M4 | 管控策略、报表、驾驶舱 |
