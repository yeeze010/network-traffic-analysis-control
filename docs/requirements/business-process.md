# 业务流程

## 1. 流量采集流程

1. 系统管理员登记采集节点。
2. 网络管理员绑定采集网卡并配置抓包策略。
3. 采集任务启动后持续上报流量元数据。
4. 平台进行聚合计算、会话入库和统计分析。
5. 驾驶舱与分析页面展示结果。

## 2. 异常告警流程

1. 检测引擎读取流量会话与统计指标。
2. 规则匹配到异常后生成告警。
3. 系统按严重级别推送到告警中心。
4. 安全管理员研判并执行处置动作。
5. 审计员复核处置结果并归档。

## 3. 策略管控流程

1. 安全管理员创建或调整管控策略。
2. 提交审批后由审批人审核。
3. 审核通过后下发到目标节点或网关。
4. 系统记录执行结果和生效时间。
5. 通过命中情况和风险下降指标评估效果。

## 4. 报表归档流程

1. 用户选择统计周期和筛选条件。
2. 系统汇总流量、告警、处置和策略数据。
3. 生成日报、周报、月报或专题报表。
4. 审计员确认后导出 PDF/Excel 并归档。
