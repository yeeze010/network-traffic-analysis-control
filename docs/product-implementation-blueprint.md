# 网络流量分析监测管控软件产品落地蓝图

## 项目定位

面向政企网络安全运营中心，建设一套覆盖流量采集、协议识别、异常检测、告警处置、策略管控、报表归档和审计追踪的可视化系统。当前版本已实现 Cursor 可直接查看的 Vite + React 前端 MVP。

## 角色

| 角色 | 职责 |
| --- | --- |
| 系统管理员 | 管理采集节点、网卡配置、用户和系统参数 |
| 安全运营员 | 查看驾驶舱、处置告警、申请管控策略 |
| 流量分析员 | 查询会话、分析协议、识别异常和输出研判意见 |
| 策略审批员 | 审批策略、发布策略、查看下发结果 |
| 审计员 | 查看报表、附件、审计日志和导出留痕 |

## 核心流程

1. 采集节点上线并上报心跳、吞吐和丢包。
2. 管理员配置节点网卡、采集模式和采集任务。
3. 平台解析会话、协议、IP、端口和应用维度指标。
4. 异常检测规则命中后生成告警。
5. 运营员完成告警状态流转：新告警、研判中、已遏制、已关闭。
6. 策略管理员创建管控策略，审批员审批后发布下发。
7. 系统生成日报、周报、策略审计报表和附件留痕。

## 功能模块

| 模块 | 当前实现 |
| --- | --- |
| 实时流量驾驶舱 | 总流量、采集节点、活动会话、策略、告警、趋势图、协议占比、应用排行 |
| 采集节点 | 节点状态筛选、节点详情、网卡模式、启停状态、采集任务入口 |
| 网卡配置 | 显示网卡名称、MAC、SPAN/TAP/备用模式、速率和启用状态 |
| 会话查询 | 源/目标 IP、协议、风险级别组合过滤和导出入口 |
| 协议分析 | 协议占比、协议异常评分趋势、协议明细 |
| IP/端口/应用排行 | Top IP、Top 端口、Top 应用三类排行 |
| 异常检测 | 横向扫描、DNS 隧道、异常峰值、弱口令爆破等规则展示 |
| 管控策略 | 可操作策略表单、草稿、待审批、已发布、下发失败状态推进 |
| 告警处置 | 告警列表、严重级别、状态闭环、SLA、责任人、相关会话 |
| 报表中心 | 日报、周报、合规报表生成和下载状态 |

## 页面清单

实时驾驶舱、采集节点、会话查询、协议分析、排行分析、异常检测、管控策略、告警处置、报表中心、产品落地、验收清单、审计附件。

## 数据模型

核心实体包括 `collector_node`、`collector_interface`、`collector_task`、`traffic_session`、`traffic_metric`、`detection_rule`、`security_alert`、`alert_disposal`、`control_policy`、`policy_publish_log`、`report_archive`、`audit_log`。前端种子数据位于 `src/data.ts`。

## 接口规划

统一 API 前缀 `/api`，统一 Bearer Token 鉴权。接口分组包括认证、驾驶舱、采集节点、采集任务、会话、协议统计、排行、规则、策略、告警、报表和审计日志。

## 报表指标

总流量、流量峰值、协议占比、Top IP、Top 端口、Top 应用、严重告警数、平均响应时间、平均处置时间、策略命中率、策略下发成功率、告警复发资产。

## 告警规则

当前前端展示规则包括横向 SMB 扫描、DNS 隧道疑似、异常出站峰值、弱口令爆破。后续可接入阈值规则、基线偏离、协议特征、黑名单命中、策略命中、威胁情报命中。

## 文件附件

附件类型包括告警证据包、策略审批 PDF、节点日志 ZIP、报表归档文件。附件需要记录文件名、类型、责任人、大小、校验值、版本和操作时间。

## Git/GitHub

保留 `.github` Issue/PR 模板和文档治理 workflow。新增 `.gitignore` 忽略 `node_modules/`、`dist/`、`.vite/` 和日志文件。合并前建议执行 `npm.cmd run build` 与 `npm.cmd run validate:docs`。

## 测试

已通过 `npm.cmd run build`。前端验收重点包括页面渲染、图表可见、筛选可用、策略表单可保存、策略状态可推进、告警状态可流转、响应式布局可用。

## 部署

固定端口由根目录 `.env.ports` 管理：前端开发 `5204`、API `8204`、生产预览 `6204`。开发启动：`npm.cmd run dev`；生产构建：`npm.cmd run build`；生产预览：`npm.cmd run preview`。Vite 将 `/api` 代理到 `http://127.0.0.1:8204`，开发与预览均启用 `strictPort`，端口冲突时禁止自动换端口。静态产物位于 `dist/`，可由 Nginx、对象存储或内网 Web 服务托管。

## 验收

验收以可运行入口、业务页面完整性、交互闭环、图表展示、报表和附件可追溯为准。应用内 `验收清单` 页面同步展示当前 MVP 的验收状态。
