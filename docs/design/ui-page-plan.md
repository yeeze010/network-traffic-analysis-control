# 页面清单与交互规划

## 1. 页面清单

| 页面 | 类型 | 说明 |
| --- | --- | --- |
| `/login` | 登录页 | 用户认证、验证码、登录审计 |
| `/dashboard` | 驾驶舱 | 实时总流量、风险趋势、Top 榜单、待办告警 |
| `/collectors` | 列表页 | 采集节点列表、状态筛选、操作入口 |
| `/collectors/:id` | 详情页 | 节点信息、接口、任务、心跳、日志 |
| `/traffic/sessions` | 查询页 | 会话检索、导出、异常钻取 |
| `/traffic/protocols` | 分析页 | 协议占比、趋势图、明细联动 |
| `/traffic/rankings` | 分析页 | IP、端口、应用排行 |
| `/rules` | 管理页 | 检测规则管理 |
| `/policies` | 管理页 | 管控策略列表与审批状态 |
| `/alerts` | 列表页 | 告警查询、批量处置、超时标记 |
| `/alerts/:id` | 详情页 | 告警详情、研判、处置、附件 |
| `/reports` | 报表页 | 报表生成、下载、归档 |
| `/system/users` | 管理页 | 用户与角色管理 |
| `/system/audit-logs` | 日志页 | 审计查询和导出 |

## 2. 关键页面交互要求

- 驾驶舱支持按时间范围刷新和风险级别筛选
- 会话查询支持多条件组合筛选和列配置
- 告警详情页必须能查看命中规则、相关会话和处置记录
- 策略管理支持草稿、待审核、已发布状态流转
- 报表页面支持异步生成和历史记录追溯

## 3. 组件建议

- 通用筛选栏
- 数据表格与列配置
- 趋势图、饼图、排行图
- 状态标签和严重级别徽标
- 审批流时间线
- 附件上传与预览
