# 部署方案

## 1. 环境规划

| 环境 | 用途 |
| --- | --- |
| `dev` | 开发联调 |
| `test` | 测试与验收演示 |
| `prod` | 正式运行 |

## 2. 部署组件

- 前端静态站点：Nginx
- 后端服务：Docker 容器
- 数据库：PostgreSQL
- 缓存：Redis
- 对象存储：MinIO
- 日志采集：结构化文件日志或集中日志系统

## 3. 推荐部署拓扑

1. 反向代理层负责 HTTPS 和静态资源发布。
2. 应用服务拆分为认证、分析、告警、策略、报表等模块。
3. 数据库与缓存独立部署，启用定期备份。
4. 采集节点与中心平台通过受控网络通道通信。

## 4. 运维要求

- 重要配置通过环境变量管理
- 数据库每日备份，保留至少 7 天
- 报表和处置附件定期归档
- 发布前执行文档校验、构建校验和基础冒烟验证

## 5. 回滚策略

- 镜像版本按标签保留最近两版
- 数据库变更必须附带回滚脚本
- 发布失败时优先回滚应用，再评估数据修复
